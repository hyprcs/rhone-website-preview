# Rhone website preview

A website concept for reviewing Rhone Refrigeration & Air Conditioning Services branding, photography and an illustrative quote experience.

The website is a self-contained static page. Quote prices are invented demonstration values and no enquiries or bookings are submitted. Selected project photos have been retouched with AI for the concept. This is not the business's official production website.

Open index.html locally, or visit the GitHub Pages preview for this repository.
